RUN LOCALLY
1. Extract this ZIP.
2. Open index.html in Chrome or Edge.
3. Use the sidebar to switch between Chat tutor, Concept library, Quick quiz, and Exam Q&A.

IMPORTANT ABOUT THE QR CODE
A QR code must point to a public URL to work on another phone. This package is ready to host, but it is not automatically published online.
Easy free hosting:
1. Create a GitHub repository (for example: files-streams-chatbot).
2. Upload index.html, style.css, and app.js to the repository root.
3. In GitHub, open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and /(root), then Save.
5. Wait for GitHub Pages to show the public URL.
6. Open that URL on your phone. Generate a QR for the URL using your browser's Share/QR feature or a trusted QR generator.
Do not scan/share a QR until it points to the published website.

NOTE
The chatbot uses a small built-in knowledge base, not a live AI API. It works offline after the page assets load, but it answers within the included topic coverage. Google Fonts is optional; if offline, the system font is used.
